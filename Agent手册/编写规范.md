# 编写规范（第 1–24 章通用）

本规范约束 `Agent手册/ch*.md` 的全部章节文件。合并脚本只收集匹配 `ch*.md` 的文件，
因此本文件与 `事实速查.md` 不会进入最终大文档。

## 1 文件与命名

- 一个章节一个文件：`Agent手册/chNN-中文短标题.md`，`NN` 为两位零填充章号（`ch01` … `ch24`）。
- 章内标题层级只允许两级：文件首行为 `# 第 NN 章 章标题`，小节为 `## NN.M 小节名`，再往下 `###` 可选。
- 不写 YAML front matter，不写图片，不引外链。仓库内文档用相对路径引用（如 `README.md 第十章`、
  `src/StartUI4Controls/UI4Theme.cs:283`）。

## 2 每章固定骨架

```
# 第 NN 章 章标题

> 本章解决：<一句话任务陈述>
> 读者：AI Agent（要在本项目之外新建/续写 WPF 业务代码）
> 前置章节：…（没有则写「无」）

## NN.1 目标与验收
## NN.2 源码依据（必读文件清单，带路径与行号）
## NN.3 正文（概念→操作→可复制片段，按小节展开，允许 4–8 个小节）
## NN.4 推荐做法（Do / Don't 成对写）
## NN.5 坑与排错（症状 → 根因 → 处置，尽量给可验证的判据）
## NN.6 完成判据（Agent 自查清单，逐条可执行）
```

`NN.1`、`NN.2`、`NN.4`、`NN.5`、`NN.6` 为强制小节；中间正文小节数量按内容定。

## 3 内容纪律（最重要）

1. **API 名称必须核实后才能写**。所有类型名、属性名、事件名、枚举值、方法签名，写之前用 Read/Grep 在
   `src/StartUI4Controls/` 或 `samples/StartUI4Demo/` 里确认存在。宁可少写一个属性，不可编造一个。
2. **区分「公开」与「内部」**：`UI4DataGrid`、`UI43DSphere`、`IThemeAware`、`Internal/*` 都是 `internal`，
   宿主不可用；提到它们时明确写「宿主不可使用」。
3. **语言级别**：所有 C# 片段必须是 C# 7.3 / .NET Framework 4.8 可编译的写法。禁止 `using var`、`is not`、
   目标类型 `new()`、可空引用类型注解、`System.Text.Json`、`Math.Clamp`、`Dictionary.TryAdd`、索引/范围运算符 `^`/`..`。
4. **XAML 片段**一律带 `xmlns:ui="clr-namespace:StartUI4Controls;assembly=StartUI4Controls"` 上下文（可在片段内省略但在
   正文说明前缀约定）。主题相关颜色/画刷必须用 `DynamicResource`，不得给宿主 `StaticResource` 写法。
5. 每条「坑」尽量给判据：能跑通的检查方式（读哪个 DP、哪条 DWM 属性、哪条日志、哪条构建输出）。
6. 面向 Agent 的指令式语气：写「先做 X，再做 Y」「若出现 Z，改为 W」，不写抒情性描述，不重复 README 原文。

## 4 交叉引用

组件库已有文档地图，按需引用而非重述：

- `README.md`：一 简介 / 二 特性 / 三 快速开始 / 四 控件一览 / 五 控件详解 / 六 从零搭建教程 / 七 Demo 工程指南 /
  八 与上游差异 / 九 附录 / 十 主题系统。
- `PORTING.md`：第 1–14 节（移植结论、构建验证、P0/P1/P2/P3 实施记录、下拉框修复、标题栏修复）。
- `主题方案分析与改进.md`：第一–十二节（架构、不足清单、P0–P3 记录、选型对比、标题栏改动清单与生效流程）。
- `常见问题清单/`：`UI4ComboBox-选中项文本溢出.md`、`UI4ComboBox-文本高度显示不全.md`。
- 历史任务规格：`src/StartUI4Controls/.qoder/specs/*.md`（只作背景，不作 API 依据）。

手册的定位是「**操作手册**」：这些文档解释「为什么」，手册解释「怎么做、按什么顺序、怎么验证」。

## 5 篇幅

每章 120–260 行 Markdown。内容不足时缩小承诺（不要注水），内容过多时把细节移到该章 `NN.3.x` 小节。

## 6 禁止事项

- 不修改 `Agent手册/` 之外的任何文件；不做 git 操作；不运行 `dotnet build`/`msbuild`（多个撰写者共用一份 bin 会互相踩）。
- 不删除或改写既有文档。
- 不在章节文件里写「本文档由某 Agent 生成」之类元信息。
